# Movimientos

The transactions ledger. The old UI labeled it *Transacciones* — going forward, everywhere it's **Movimientos**.

The page where the user scans, reconciles, categorizes, and finds the line items that explain what's already summarized on Saldos. *Saldos = where I stand. Movimientos = what moved.*

Drafts, specs, and explorations for the Movimientos surface go here.

## Naming rationale

- Native vocabulary in VE/LATAM banking — every bank app and extracto says "movimientos"
- Job over object — names what the user is reading for, not the underlying row type
- Pairs with Saldos as a couplet (state-noun + action-noun, both in user vocabulary)
- Same playbook as the Saldos rename — see [[../saldos/index]]
