# Rails

Per-bank research, API specs, and validation tickets for the rails powering Tesote Pay.

One subfolder per bank. Each folder owns:
- API spec extractions from vendor docs
- Validation tickets (mirroring the corresponding Linear ticket in the Payments project)
- Roadmap notes, contact info, integration status
