## Solo QA — Tesote AI pre-created reports: category cash flow is structurally blocked

Tested the pre-created reports flow in Tesote AI, collecting convo IDs as bugs surfaced (the convo-ID feature from PR #7154 paying off immediately). Claude replayed the exact `tesote-workspace` MCP surface the agent uses and root-caused all three — these aren't prompt bugs, the tool surface can't deliver.

**The headline: a category-based cash flow report is impossible for the agent today.** Every path blocked, verified empirically:
- `report.run` cash_flow type → inflow/outflow/net only, no category dimension.
- `group_by: "category"` → **silently ignored** (no error, same ungrouped output). Worst failure mode — agent can confidently report wrong/incomplete numbers.
- `cash_flow_by_category` report type → doesn't exist (valid: cash_flow, balance_over_time, balance_changes_by_bank, cash_flow_by_counterparty).
- Fallback via `transaction.search` → hard 100 cap, no pagination, no category filter, no aggregation. My last 30d on 3 USD accounts alone = 116 txns. Dead end.

**The three convos:**
- `5a192f50` — no report produced. Compounding traps: only **1 saved definition exists** in the workspace (created today mid-test — "pre-created" may have been zero at convo time); `report.run` w/o account_ids always errors on mixed currencies (33 accts, USD/VES/EUR); `period: "last_month"` rejected (enum-only presets).
- `f9003145` — worked but money in/out only → that's the tool's ceiling, not an agent failure.
- `71ec2c5d` — agent did the right things in the right order; surface couldn't deliver (group_by ignored → 100-cap fallback died).

**Cheapest fix:** `cash_flow_by_category` as a 1:1 mirror of `cash_flow_by_counterparty` — grouped-report shape already exists server-side, tx rows already carry category IDs. Caveat from the counterparty run: **uncategorized = 70% of volume** — the category report will have the same hole until grooming catches up; surface it loudly.

**Artifact:** [[../product/ai/qa-pre-created-reports-2026-06-03]] — running QA log w/ full repro evidence + ranked 6-item fix spec (new report type / error-on-unknown-params / mixed-currency ergonomics / tx pagination / preset aliasing / definition seeding).

## Sidebar — Tesote as the company's AI layer (expansion thesis)

Wild-idea session, deliberately off the execution track. The thought: we're super deep into Claude Code + MCPs and slowly building our own org-wide AI brain — and even Fortune 500s struggle to do this (that's the whole Accenture/Anthropic deployment business). Our customers will *never* get that option. So what if Tesote AI's horizon isn't the finance team but the **whole company** — email, internal comms, org knowledge, the works?

**Claude's read (I buy it):**

- The observation is correct — the 2026 constraint is **deployment** (context, integrations, org memory), not model capability. The "markets global software forgot" logic extends to AI deployment 1:1.
- But the naive version collides head-on with [[../product/ai/winning-vs-horizontal-ai]]: narrow+deep beats broad+shallow (Pattern 7), and company-wide "summarize my email" chat is exactly the surface where Copilot/Glean/Claude Enterprise compete and where our five moats (rails, VE ontology, action layer, audit, multi-player) don't apply.
- **The reconciliation: it's a sequencing question, not either/or.** Moat #1 already says finance is N systems — AP forces email ingestion, cobranza forces WhatsApp, counterparties force CRM-ish data. The company-wide context graph gets built *as a byproduct of the finance wedge*. Finance is the trojan horse (money data = highest-trust integration in the company), and the "Tesote is our company's AI" moment happens naturally in 2027+ when the CEO notices the finance AI already knows more about the company than anything else they own. This is Harvey's literal trajectory — narrow was the entry, not the ceiling.
- If/when we expand, the differentiated axis is **action, not retrieval** — Glean/Copilot search and summarize; Tesote sends payments, posts entries, fires WhatsApps. "System of action" scales beyond finance without becoming generic chat.

**Verdict: right vision, wrong year.** Worth three things *today*, zero roadmap:

1. **Architecture ask for Dan** — connectors / org memory / agent-state should be **org-scoped, not finance-scoped**, so nothing built this quarter forecloses the option. Cheap now, expensive later.
2. **Investor narrative** — "finance is the wedge; the company's AI layer is the prize" turns the 10x story into a 100x TAM slide. Costs nothing.
3. **Dogfood proof extends** — "we run our own books on it" → "we run our own *company* on it." We're already the prototype.
