# KYC/KYB Checks

Per-customer KYC/KYB screening records. One file per entity, date-prefixed (`YYYY-MM-DD-entity-slug.md`). Each file captures:

- Source document (acta, registro mercantil, RIF, IDs)
- Persons + entity screened (with cédulas)
- Database(s) used and result
- Caveats and recommended follow-ups

Companion to [[kyc-customer-collection-design]] — the design defines *what* we collect; this folder is the *record* of what we did per customer.
